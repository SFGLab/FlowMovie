# ChromMovie MD Simulation Modules

This file summarizes the steps of the standard ChromMovie simulation preparation as part of the FlowMovie pipeline as well as provides instructions on how to run them.

The ChromMovie algorithm can be dowloaded with:

```{bash}
git clone https://github.com/SFGLab/ChromMovie.git
```

See the `https://github.com/SFGLab/ChromMovie` for instructions on installation and usage.

## preprocess_contacts.py

**Preprocessing fuctions for creating ChromMovie simulations.**

The scripts takes the `test_name` and creates the `.csv` files for the ChromMovie simulation according to specification. The algorithm works by connecting random points from three parts of the interphase: G1, S and G2 and connecting them with the cubic splines. It then draws cells along those trajectories for the ChromMovie simulation.

From `./src/md` folder prepare the data:

```{bash}
python preprocess_contacts.py -t test02 -s "../../data/unique_cells_PATSKI_1k.txt" -c "../../data/final_dataset_downsampled_1k/filtered_ChIA-PET.bedpe" --n-traj 10 -n 3 -m 10
```

## prepare_CM_configs.py

**File for preparing the configuration files before running ChromMovie simulations.**

The script takes the template configuration file and copies all of its parameters to create appropriate config files for all of the trajectories generated by `preprocess_contacts.py`. 

Then prepare the configs:

```{bash}
python prepare_CM_configs.py -t test02
```

## Running of the ChromMovie simulation

After installing ChromMovie software, preparing the dataset with `preprocess_contacts.py` and preparing the configuration files with `prepare_CM_configs.py` the ChromMovie simulations are ready to me performed.

To run the simulations, in the `./scripts` folder run the following (might need to specify the configs directory and ChromMovie folder):

```{bash}
./run_CM_simulations.sh ../configs/md/test02/ ../../ChromMovie
```

Alternatively:

```{bash}
for file in /home/baneckik/Documents/projects/2026_FM/FlowMovie/configs/md/test01/*.yaml; do python3 ../ChromMovie/ChromMovie.py -i "$file"; done
```

## clean_CM_directory.py

**A script for the removal of the unnecessary files resulted from the ChromMovie simulation.**

The script deletes all the files in the output directory from the ChromMovie simulation except for the cif files of the structures from the last step and the YAML configuration file. The output directory is determined from the YAML file in yaml_path.

All of the files in the determined output directory are expected to contain a specific ChromMovie simulation output.

This script is already used in the `scripts/run_CM_simulations.sh` script to save space during the ChromMovie simulations.
